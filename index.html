Contexto

Um clássico com quase 50 anos

A ideia é simples e viciante: guiar uma cobra que cresce a cada comida, sem bater em si mesma nem nas paredes. É simples de entender e difícil de dominar, e por isso é um ótimo primeiro projeto de programação.

A grande sacada do vídeo

O corpo é um rastro de clones

  • 1A cada 0,1 s a cabeça deixa um clone de si mesma onde está e anda 28 passos.
  • 2O clone vira um quadrado preto (corpo) e fica parado.
  • 3Ele espera 0,1 × pontos segundos e se apaga.
  • =Resultado: sempre existem “pontos” pedaços de corpo. Quanto mais pontos, maior a cobra! 🐍
pontos = 4

Arraste para mudar pontos e veja a cobra crescer. Os números mostram quanto tempo falta para cada clone sumir.

2

Criando a variável pontos

  • 1Abra a categoria Variáveis e clique em Criar uma Variável.
  • 2Dê o nome pontos.
  • 3Escolha “Para todos os atores”, porque a comida muda o valor e a cobra lê o valor.
  • 4Deixe a caixinha marcada para mostrar o placar no palco.

Uma variável, duas funções

A variável pontos é usada de dois jeitos:

🏆 Placar
mostra quantas comidas a cobra comeu.
📏 Tamanho
define quanto tempo cada pedaço do corpo fica na tela.
Obs.: o Scratch já cria uma variável chamada minha variável. Ela não é usada e pode ser apagada.
3

Fazendo a cobra andar

ator: cobra
Script 1 
quando @greenFlag for clicado
mude para a fantasia [rosto v]
mude para o cenário [jogo v]
vá para x: (-160) y: (3)
aponte para a direção (90)
sempre
  crie clone de (mim mesmo v)
  mova (28) passos
  espere (0.1) seg
end
  • 🎭Reinicia o visual: cabeça com rosto e cenário “jogo”, apagando o “FIM DE JOGO” da partida anterior.
  • 📍Posição inicial à esquerda (-160, 3), virada para a direita (90°).
  • 🔁Laço do jogo: deixa um clone, anda 28 passos e espera 0,1 s. É o “relógio” do jogo.
Por que 28 passos? A cobra tem ~27 px de largura. Andando 28, a cabeça sai do quadrado onde estava e não encosta no clone que acabou de criar.

5

Criando o corpo com clones

ator: cobra
Script 3 
quando eu começar como um clone
mude para a fantasia [corpo v]
espere ((0.1) * (pontos)) seg
apague este clone
Só 4 blocos e a cobra já cresce sozinha conforme os pontos aumentam!
  • 1Esse script só roda nos clones, não na cabeça.
  • 2O clone troca para a fantasia corpo (quadrado preto).
  • 3Espera 0,1 × pontos segundos. Use o bloco verde ( ) * ( ) de Operadores.
  • 4Depois disso some, que é a ponta do rabo saindo.
A matemática: sai 1 clone a cada 0,1 s e cada um vive 0,1 × pontos s. Então ficam pontos clones na tela ao mesmo tempo. Com 0 pontos, o clone some na hora e só aparece a cabeça.
6

Detectando o fim de jogo

ator: cobra
Script 4 
quando @greenFlag for clicado
sempre
  se <tocando na cor [#060606]?> então
    mude para o cenário [fim v]
    pare [todos v]
  end
end
Escolhendo a cor: clique no quadradinho de cor do bloco, use o conta-gotas e clique no corpo da cobra.

🐍 Bater no próprio corpo

O corpo tem contorno na cor #060606. Se a cabeça encostar nele, o cenário vira “FIM DE JOGO” e tudo para.

🧱 E a parede?

Não existe bloco de parede! O Scratch não deixa o ator sair do palco. Na borda a cabeça fica presa, encosta no clone que acabou de criar e… fim de jogo.

Atenção: a cor do bloco precisa ser exatamente a do corpo. Uma cor parecida não serve.
7

Programando a comida

ator: comida
Script 5 
quando @greenFlag for clicado
mude [pontos v] para (0)
vá para (posição aleatória v)
sempre
  se <tocando em (cobra v)?> então
    vá para (posição aleatória v)
    adicione (1) a [pontos v]
  end
end
  • 0Zera o placar no começo de cada partida.
  • 🎲Aparece em uma posição aleatória do palco.
  • 👀Fica conferindo sem parar se a cobra encostou nela.
  • +1Quando a cobra encosta, ela muda de lugar e soma 1 ponto, e a cobra cresce na hora.
Pronto! Clique na 🚩 bandeira verde e jogue. O jogo está completo. 🎉

  • 5Zera pontos e sorteia o lugar. Se for tocada: troca de lugar e soma +1
Escreve na variável pontos
Ideia principal: os atores não “conversam” diretamente. A comida altera pontos e a cobra só lê esse valor. Uma variável compartilhada já basta para ligar as duas partes do jogo.

Deu errado? Veja os problemas mais comuns

SintomaProvável causa → solução
Perde logo no começoOs passos estão menores que o tamanho da cobra. Use 28 passos com tamanho 30, ou diminua o tamanho.
A cobra não cresceA variável pontos foi criada “só para este ator”. Recrie como “para todos os atores”.
Bate no corpo e nada aconteceA cor do bloco tocando na cor está diferente. Use o conta-gotas no corpo.
A cobra toda fica com rostoEsqueceu o mude para a fantasia [corpo] no script do clone.
“FIM DE JOGO” não sai na nova partidaFalta o mude para o cenário [jogo] no início do Script 1.
